# Guilherme Teles — Portfolio

Static personal portfolio: plain HTML, CSS and JavaScript, with GSAP + ScrollTrigger for scroll animations.

- `index.html` — the whole page
- `img/` — project screenshots and photos
- `certs/` — certificate images
- `docs/` — résumé (PDF)
- `vercel.json` — security headers (CSP, HSTS, X-Frame-Options, etc.) and caching

Deployed on Vercel. No build step.
